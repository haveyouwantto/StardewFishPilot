# 星露谷自动钓鱼

一个给我自己折腾用的星露谷钓鱼小游戏辅助。先说清楚：这东西高度实验性，我从头到尾都在跟检测噪声、输入延迟和游戏手感打架，不敢保证它在你机器上能钓上鱼，更不保证稳定。纯属学习研究，用的时候自己看着办，我不对它造成的任何损失负责。

## 它大概是怎么工作的

流程上分两段。第一段是找 UI：用 ui_full.png 这个模板在全屏里找可疑的钓鱼面板，找到后裁出来跑检测，只有真的在框里认出鱼才锁住这个区域，之后只截这块 ROI，不再全屏瞎扫。第二段是认鱼和条：鱼默认走我自己标数据训的 YOLO（small 模型，RTX 上跑 FP16），条走传统视觉，在鱼检测框的 y 范围里找绿色矩形。两种可以随时切，也可以只用一个，overlay 上按 F6 循环 CV / Mixed / YOLO。

控制部分我试过不少路子，最后留下来两套：一套是带 PDM 调制的 PID（按误差大小决定按多久），另一套是在模拟器里训的强化学习策略。RL 那条路花的时间最多：先照着 ramenchef.net 那个网页版钓鱼游戏，把物理和行为（mixed/dart/smooth/floater/sinker）用 gym 环境完整复刻了一遍，然后为了让策略别只会在完美模拟器里玩，给环境加了 20Hz 决策、位置测量噪声和输入延迟的域随机。训出来的效果在模拟器里还行，真机上好不好用还得看你实际跑。

## 技术栈

- Python + uv 管理环境
- ultralytics YOLO，用自己的截图和标注训 fish/bar 两个类
- OpenCV：UI 模板匹配、鱼图标模板、HSV 绿色矩形检测
- mss 截屏、pynput 模拟按键、pywin32 做透明 overlay 调试框
- gymnasium + stable-baselines3 (PPO) 做 RL 训练，模拟器参考了 ramenchef 的 JS 实现
- 训练好的模型在 rl_fishing/models，默认不提交 git，可以自己重训

## 怎么跑

直接跑主程序：

```
uv run python main.py
```

启动后会打出一个全屏透明 overlay。热键不多：F8 开始/暂停，F7 切换 RL/PID（切换会在暂停或当前局结束后才生效，不会钓鱼中途突然变），F6 切换检测模式，F9 退出。默认控制模式写在 main.py 最上面那个 CONTROL_MODE 全局变量里，想省事直接改那里。

如果想把 RL 重新训一遍：

```
uv run python rl_fishing/train.py --timesteps 200000
```

训练环境默认是 20Hz、每局随机 1~4px 测量噪声和 1~3 tick 输入延迟。想复测当前 PID 在这个模拟器里什么水平，跑 rl_fishing/test_pid_gym.py 就行。

## 已知的毛病

- 游戏里那个进度条我还没去读，RL 观测里的 progress 是个固定估计值，所以它不知道你“快赢了”。
- 钓鱼等级只按 level 0 训过，不同等级 bar 长度不一样，策略不一定跟手。
- 真机帧率如果只有十几帧，对任何算法都不太友好；模拟器里 60Hz 和 20Hz 的差距肉眼可见。
- CV 的鱼模板只能匹配长得一样的鱼，不同鱼种会漏。
- 这套东西只在固定分辨率/窗口下验证过，换个窗口大小大概率要重新调 ROI 和模板。

反正就是：别当成品用，当个实验玩具看就行。今天先到这，改天再继续折腾。
