这个仓库是给星露谷钓鱼小游戏写的一个辅助脚本，本来只想练练手，结果越搞越大，现在连强化学习都塞进去了。先说句实话：它高度实验，我在自己机器上都没做到稳定好用，所以别指望拿去就能挂机，翻车了我可不背锅。

思路其实不算复杂：先截屏找钓鱼面板，确认里面有鱼之后才把那一小块锁住，之后只盯这个区域。认鱼用的是自己标注训练的小 YOLO 模型，认条用的是传统 HSV 绿色矩形，而且只在鱼检测框的 y 范围里找，不然容易被进度条或者别的绿色骗到。

控制上先写了个带 PDM 调制的 PID，后来嫌手感不对又去折腾强化学习。RL 这边是照着 ramenchef.net 那个网页钓鱼游戏，把物理抄成了 gym 环境，再加了 20Hz 决策、测量噪声和输入延迟的随机化，不然策略只在完美的模拟器里厉害，一上真机就露馅。目前模拟器里表现我能接受，真机只能说还行。

用到的东西就是 python/uv、ultralytics、opencv、mss、pynput、pywin32，RL 那边是 gymnasium 加 stable-baselines3。数据集是自己截的图自己标的，训练和测试脚本都放在 rl_fishing 里，模型没提交，想重新训随时可以跑。

跑起来很简单：`uv run python main.py`。F8 暂停/开始，F7 在 RL 和 PID 之间切换（要等暂停或者这局结束才生效，不会钓鱼中途突然变），F6 换检测方式，F9 退出。想改默认模式，动 main.py 顶上的 CONTROL_MODE 就行。

重训就是 `uv run python rl_fishing/train.py --timesteps 200000`，想看看 PID 在模拟器里什么水平就 `uv run python rl_fishing/test_pid_gym.py`。

没解决的坑还挺多：进度条一直没读，RL 其实不知道你快赢没赢；只按钓鱼等级 0 训的，等级高了条变长不一定跟得上；真机帧率只有十几帧的时候，什么算法都不好使；CV 那个鱼模板换个鱼种就认不出来；换分辨率还得重新校准。

就当个玩具吧，别当真。
